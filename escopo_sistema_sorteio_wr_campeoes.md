# Sistema de Sorteio WR — Escopo de Campeões, Rotas e Links

## Objetivo

Criar um sistema de sorteio de campeões do Wild Rift com suporte a sorteio geral e sorteio por rota. O sistema deve trabalhar com **141 campeões únicos** e permitir que um mesmo campeão pertença a várias rotas.

## Regras de negócio

- O cadastro deve conter **141 campeões únicos**.
- Um campeão **não deve ser duplicado no banco** apenas por atuar em mais de uma rota.
- Cada campeão deve possuir um campo `rotas` contendo uma ou mais posições.
- O filtro **Todos** deve sortear entre os 141 campeões únicos.
- Os filtros **TOP, JUNGLE, MID, ADC e SUPPORT** devem usar o campo `rotas` para formar o pool do sorteio.
- Campeões flex devem aparecer em todos os pools correspondentes às suas rotas.
- Cada campeão deve possuir `nome`, `rotas`, `imagem` e `link`.
- Ao clicar no campeão ou em um botão como **Ver counters e builds**, o sistema deve abrir a página correspondente do Wild Rift Core em uma nova aba.
- A tela de lista de campeões deve permitir pesquisa por nome.
- A imagem do campeão poderá ser cadastrada posteriormente por URL ou arquivo local.

## Estrutura recomendada

```json
{
  "nome": "Aatrox",
  "rotas": ["TOP", "JUNGLE"],
  "imagem": "URL_OU_CAMINHO_DA_IMAGEM",
  "link": "https://wildriftcore.com/pt-br/champions/aatrox/"
}
```

## Observação de implementação

A melhor estrutura é manter apenas um registro por campeão. O campo `rotas` decide em quais sorteios ele poderá participar. Dessa forma, um campeão como Malphite pode participar de TOP, MID e SUPPORT sem existir três vezes no banco, enquanto o sorteio **Todos** continua contendo exatamente 141 opções.
